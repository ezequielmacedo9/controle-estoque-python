# Sistema de Controle de Estoque em Python

Projeto desenvolvido em Python com o objetivo de gerenciar produtos em estoque.

## Funcionalidades
- Cadastro de produtos
- Atualização de informações
- Remoção de produtos
- Consulta de itens no estoque
- Menu interativo no terminal

## Tecnologias utilizadas
- Python
- Lógica de Programação
- Estruturas condicionais e de repetição

## Como executar o projeto
1. Certifique-se de ter o Python instalado
2. Execute o arquivo principal pelo terminal:
   python main.py

## Observações
Projeto desenvolvido para fins acadêmicos e prática de lógica de programação e Python.
